# Alex Morgan — portfolio

A responsive, one-page portfolio built with plain HTML and CSS.

## Link
- https://mor1shi.github.io/cgtp-site/

## Structure

- `index.html` — page structure and content
- `assets/css/style.css` — all styles, responsive layout, duotone artwork

## Run locally

Open `index.html` in your browser. No build tools, JavaScript framework, or package installation is required.

## Customize

- Replace the fictional name, bio, project names, and email address in `index.html`.
- Edit the color tokens at the top of `assets/css/style.css`.
- The project artwork and portrait are built from CSS shapes, so no image assets are required.
- The Google Font DM Sans loads online; the page falls back to system sans-serif if unavailable.

## Notes

The portfolio content is fictional placeholder content. Project cards link to the contact section and are intended to be connected to real case studies when available. No animations or JavaScript are used.
